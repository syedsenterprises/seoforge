Data sources & honest limits

What each tool measures — and what it never invents
  • Site Audit: your sitemap fetched through our server-side proxy; PageSpeed Insights (Google). Scores come from Google's API through SEOForge's server key — if the quota is exhausted, the app says so instead of showing a fake score. Your own free API key in Workspace settings uses your own quota instead.
  • Keyword Explorer: live suggestions from Google Suggest. Search volume is not available without a paid keyword API — it is never invented here.
  • Rank Tracker: checks Bing results, not Google (DuckDuckGo blocks our server, so it is only a fallback). Position is honest for that source only.
  • Link Verifier: reads the live linking page and reports the real rel attribute (dofollow / nofollow / sponsored / ugc).
  • Ad Revenue: manual logging only in v2. Network synchronization is not currently available.
  • Backlink index: there is no free Ahrefs/Semrush backlink index. SEOForge does not fake one — verify links directly with the Link Verifier.
  • Keyword Difficulty: an estimate from the live Bing top 10 (authority domains, exact-match titles, .gov/.edu) — not a paid index.
  • Redirect chains: free proxies follow redirects on their own servers, so intermediate hops are only shown when the proxy exposes them; the final URL is shown when it can be read.
  • Revenue Estimator: typical published AdSense RPM ranges by niche — an estimate, never a promise.
  • Content briefs: headings and word counts come from reading the live top 5 pages (from Bing search results); questions come from Google Suggest.
  • Compare: when a page cannot be read, the table says so — no numbers are shown for it. A failed fetch is never measured as data.
