WordPress connection

Publishing talks directly from this browser to your own WordPress site. Nothing is sent to an SEOForge server.

In WordPress, go to Users, then Profile, then Application Passwords, and create one named SEOForge. Use that password here, not your login password.

If unchecked, the connection is kept only while this page is open. The Application Password is never sent anywhere except your own site.

Editor

Saving is explicit, and the open editor also autosaves as you type. In WordPress, open Tools, then Import, then WordPress. Review the imported post under Posts, then Drafts, before publishing.

Publish to WordPress

Connect WordPress above to publish from here.

Find the media ID in your WordPress Media Library: open the image and read the ID from the URL, after post=. Category and tag names must already exist on your site; names that do not match are left out and listed after publishing.

AI prompt builder

Paste the prompt into Forge Assistant or your preferred AI tool. The studio does not send your notes to an AI provider.

Agent runs

A guided run for one page: fetch it, audit it, then brief, outline, draft and check it, one step at a time. Each step can run or be skipped, and every output stays editable. AI steps use your own key from the app Settings, through the same ai-agent service as Forge Assistant.

No key yet? Open the SEOForge app, go to Settings, and add a free key (NVIDIA or a free Gemini key from Google AI Studio), then return here.

WordPress site check

Checks whether the connected site exposes its REST API, a sitemap and robots.txt. Where the browser is blocked from reading the site directly, the check falls back to the fetch proxy.

Run the check to see results here.
