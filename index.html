Data sources & honest limits

  • Site Audit: your sitemap fetched through a free public proxy; PageSpeed Insights (Google, free, no key). Google's no-key quota is shared and often exhausted — if it returns 429, add a free API key in Ad Revenue → Settings, or retry later.
  • Keyword Explorer: live suggestions from Google Suggest. Search volume is not available without a paid keyword API — it is never invented here.
  • Rank Tracker: checks DuckDuckGo results, not Google. Position is honest for that source only.
  • Link Verifier: reads the live linking page and reports the real rel attribute (dofollow / nofollow / sponsored / ugc).
  • Ad Revenue: manual logging only in v1. Live sync needs your network API keys (v2).
  • Backlink index: there is no free Ahrefs/Semrush backlink index. SEOForge does not fake one — verify links directly with the Link Verifier.
